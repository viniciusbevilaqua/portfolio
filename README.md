# Portfólio

Portfólio pessoal de **Vinícius Bevilaqua**, estudante de Ciência da Computação e desenvolvedor Java.

O projeto reúne minha apresentação, trajetória, projetos selecionados, aprendizados atuais e currículo em uma interface responsiva com temas claro e escuro.

## Tecnologias

- React + TypeScript
- Vite
- Wouter (rotas)
- CSS responsivo
- Lucide React (ícones)

## Executar localmente

Você precisa ter Node.js e pnpm instalados.

```bash
git clone https://github.com/viniciusbevilaqua/portfolio.git
cd portfolio
pnpm install
pnpm dev
```

Depois, abra o endereço local mostrado no terminal.

Para gerar a versão de produção:

```bash
pnpm build
```

## Conteúdo

- Página inicial com apresentação e animações de entrada
- Seção Sobre
- Projetos selecionados com links para os repositórios
- Página Aprendendo
- Currículo para visualização e download
- Alternância entre temas claro e escuro
- Navegação adaptada para desktop e mobile
